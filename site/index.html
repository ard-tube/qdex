QDEX

YOUR MAC, AT FULL SPEED.

A keyboard-first terminal command center. Find folders, open files and launch apps without leaving your terminal.

[ INSTALL QDEX ]
# Homebrew (recommended)
brew install ard-tube/qdex/qdex

# Or use the setup installer
curl -fsSL https://ard-tube.github.io/qdex/install.sh | sh

01 // MOVE FAST

Live fuzzy search, arrow-key navigation, and instant access to your folders.

02 // LAUNCH ANYTHING

Search your installed Mac apps and open them right from the command center.

03 // STAY IN CONTROL

Copy and move files with clear keyboard shortcuts and no accidental overwrites.

MAKE IT YOURS
Qdex asks your name and preferred starting folder on first launch. For the full-screen neon look, open Terminal → Settings → Profiles, choose the built-in Pro profile, and click Default.
